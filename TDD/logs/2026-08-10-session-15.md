## Three real engine bugs (found by owner ear + forensics; full detail in `tools/strudel_extractor/IMPLEMENTATION-NOTES.md`)

1. **Phantom high note (m2, then m1):** vendored 1.3.0 **no-ops bare-scalar arithmetic on control patterns** (`ZA` guard: "Can't do arithmetic on control pattern") — `.off(1/8, x => x.add(-12)…)` echoes played UNtransposed. Diagnosed via hap dumps (echo notes identical to originals). Fixed with a **marked patch inside `vendor/strudel-web.js`** ("EXTRACTOR PATCH") remapping the scalar onto note/n; verified: echoes now exactly one octave down. A page-level wrapper was impossible (`Pattern.prototype.add` is a non-configurable getter).
2. **Missing voices in automated runs (the batch killer):** superdough's effect worklets (shape/coarse/…) load via **`initAudioOnFirstClick` — a one-shot mousedown listener registered during `initStrudel()`**, i.e. AFTER the Process click in this tool — so in single-click sessions the worklets never loaded and every `.shape` voice died per-trigger (console: `[getTrigger] error … 'shape-processor' is not defined`). m1's bass + guitar chords vanished → "loops the beginning without a main chord". Fix: `ensureEngine` calls `strudel.initAudio()` explicitly and **verifies** with a probe `AudioWorkletNode('shape-processor')` — fail loud, never degrade silently.
3. **Queue-restart corruption:** stopping/restarting the scheduler between queue files produced missing notes/wrong timings on file 2+. Fix: **never stop the clock** — it free-runs on silence for the whole session; takes swap patterns in shifted onto a future whole cycle (`.late(c0)`), window-filtered `0 ≤ begin < end` (the lower bound kills a pre-roll artifact where negative cycles wrap alternations to their last entries). Machine-verified: a file-2 capture matched the solo reference onset-for-onset within ±5 ms.
